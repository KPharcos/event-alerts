1. One poll run: ingest, the 24-hour window, the match loop and retries

The whole system is driven by poll_events, run by cron behind flock -n, so this comes first. One run has four phases: fetch every source into Event rows, mark old feed events done, match the rest newest first (stopping after three failures in a row), then re-send failed notifications from earlier runs. The models are here because this is the first code that writes them.

An event leaves Unmatched once: aged out, or matched. A Claude failure keeps it for the next run.

85 def process(self, event, alerts):

No active alerts means no Claude call; the event is still marked matched (spec row NO_ALERTS).

87 if ids is None:
88 return False # matcher failed; leave matched_at null so the next run retries

None from the matcher means "try again later" (API error). The event keeps matched_at empty and the caller counts a failure.

90 for alert_id in ids:

Safe lookup: the matcher only returns ids that were in alerts (it intersects them), so by_id always has the key.
